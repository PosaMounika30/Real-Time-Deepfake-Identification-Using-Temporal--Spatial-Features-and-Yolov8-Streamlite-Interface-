Deep Fake Detection System

Uncovering the Truth in Media with AI

Our project focuses on detecting deep fake content using advanced deep learning techniques. With the rise of synthetic media, it has become essential to identify and mitigate the impact of manipulated videos, audios, and images. By leveraging the power of AI, our system offers a robust solution for detecting deep fakes in real-time.

🎧

Audio Deep Fake Detection

Using CNNs to detect manipulated speech patterns and unnatural audio features for identifying deep fake audio.

🖼️

Face Image Deep Fake Detection

Using YOLOv8, YOLOv10, EfficientNet, and Fast-CNN for detecting fake faces in images and verifying authenticity.

📹

Video Deep Fake Detection

Using CNN-RNN models to analyze temporal and spatial features for detecting fake videos that blend audio and visual elements.



Project Abstract



This project presents a hybrid deep learning framework for detecting deep fakes using temporal and spatial features across three modalities: audio, face images, and videos. For audio detection, a Convolutional Neural Network (CNN) is employed to identify anomalies in speech patterns. Face image detection is handled using advanced models such as YOLOv8, YOLOv10, EfficientNet, and Fast-CNN to classify whether the image is real or fake. For video deep fake detection, a CNN-RNN architecture is used to capture both spatial and temporal features for more accurate detection. The system is integrated with a web interface, allowing users to efficiently upload and analyze media, providing an accessible tool for detecting deep fakes in diverse content.
